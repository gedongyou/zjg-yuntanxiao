## 这是什么

三百六十亩的校园、二十八个专业，家长开放日一趟看不完，人在外地的还回不来。这个站点把看校园和办招生这两件事都搬到线上：**六段用来看，四段用来办。**

## 五心怎么放进去的

「五心」是这所学校的育人体系：**红心铸魂 · 仁心修身 · 恒心砺学 · 匠心强技 · 创心赋能**。

五心不是五个装饰图案，也不是贴在板块末尾的五个词，它是贯穿全站的一条线：

- **首屏**：五枚印章，点任一权直接滚到对应五心段落并展开
- **五心育人整段**：每颗心六个层次——体系表述、一句话、校内具体场景、落在哪几个站、主要养这颗心的专业、一条可核对的硬数字
- **第 4、5 层是按钮**：「智造车间」跳到七站导览并展开该站，专业名跳到系部专业并定位
- **三处贯穿**：成长路径六步、按心筛 23 个专业、自测五条条形图，用的是同一套五心 id

判断标准很简单：**把五心删掉，页面会不会缺东西。** 这一版会缺四处——专业没办法按心筛、自测没有结果维度、七站没有归属、首页少了招牌。

## 线上招生四通道

| 通道 | 做什么 | 结果 |
|---|---|---|
| 在线报名登记 `#applyForm` | 六字段 + 23 专业多选 | 报名号 `YT + 年月日 + 两位序号` |
| 预约探校 `#visit` | 五个周末场次，每场 40 名额，带余量条 | 预约码 `V场次-四位` + 到校路线 |
| 专业匹配自测 `#quiz` | 六题四选一，选项带五心权重 | 五心画像 + 三个推荐专业 |
| 报名进度查询 `#checkForm` | 报名号 + 手机号 | 四步进度条走到哪一步 |

**关于数据**：本版是纯静态站，没有服务器也没有数据库。报名号、预约码存在本机浏览器（`localStorage`），刷新和关页面都还在，**换设备就查不到**——页面上已如实写明。

这样设计的三个原因：

1. 不收集未成年人真实信息，避免数据安全和隐私责任
2. 学校正式录取必须走教育局中招平台，网页上的「预登记」不能替代志愿填报
3. 纯静态才能拷进 U 盘、双击就能演示，断网也能开

真要上线收单，只需把两个函数里的 `localStorage` 换成一次 `fetch` 请求，前端不用动结构。

## 技术

- 原生 HTML / CSS / JavaScript，**零依赖、不引第三方库、不引在线字体**，断网可开
- 内容与版式分离：`content.json`（数据源）→ `tools/build.mjs` → `assets/js/site-data.js` → 前端渲染
- 颜色全部由六个 CSS 变量派生（纸色、次纸色、墨色、主红、金、天空），五心各有主色只用在印章、色带、条型与筛选按钮
- 三级文字层次（主标题 / 正文 / 辅助），用 `color-mix()` 按比例混色而不是 `opacity`
- 长卷滚动用 `position:sticky` + `transform`，不劫持滚动事件、不调 `preventDefault()`，移动端改 `svh` 单位适配 iOS 地址栏
- 响应式：1180 / 980 / 760 三档断点，390 宽实测无横向滚动

## 内容后台

两种模式，都不用装东西：

**免安装**：双击 `admin/index.html`，默认口令 `admin123`，改完点「保存」再点「导出文件」，得到 `content.json` 与 `site-data.js` 覆盖回项目根目录和 `assets/js/`。

**本地服务**：双击 `启动后台.bat`（需 Node.js），打开 http://127.0.0.1:7717/admin/ ，保存直接写本机文件，刷新前台立即可见。

后台共 14 张卡片、25 组固定问答，五心（5 颗 × 六段结构）、自测（6 题 × 4 选项 × 五心权重）、预约（5 场 × 名额余量）都能改。

命令行改内容：编辑 `content.json`，然后 `node tools/build.mjs`。

## 还没做的

- 报名与预约没有真正上传，换设备查不到（页面已如实说明）
- 探校场次的「已约人数」是写死的，非实时余量
- 自测权重是人工设定的，还没用真实报名数据校准
- 五个系部的实训室照片用的是官网图文采集的现有图，清晰度与构图层次不齐
