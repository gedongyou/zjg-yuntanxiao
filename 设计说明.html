01选题与定位

招生季的痛点很具体：家长在外地、在上班、在带孩子，来一趟学校要半天；招生老师手里只有一张宣传单和几张照片，说不出"这个专业到底在哪个楼上课"。

这个作品把开放日搬到线上——点开链接就能看校园、看专业、看作品。它不是宣传册的电子版，而是一条可以自己走的路线：七个站点，点开哪一站就看哪一站，最后停在招生信息上。

  • 服务对象：初三学生与家长、招生老师、来校参观的初中学校
  • 使用场景：招生宣传推文里的链接、开放日预约后的提前踩点、外地家长随时查看
  • 与"为学校设计数字形象"的关系：这是学校数字形象里"可进入"的那一层——官网告诉你学校是什么，这里让你走进去
  • 边界：不替代官网的信息发布，不做报名与缴费，预约只做展示与引导

第二版按指导老师的意见改了两处：一是版式的层次（标题、正文、辅助三级在颜色和透明度上分开，细节与对齐重新收过），二是补了一套内容后台——页面里的文字、图片、板块顺序、问答库都能自己改，不用再找人改代码。后台在第 07 节说明。

02五心落在哪

五心不单独设一个板块去讲，那样像贴标签。做法是把它们放进具体的展项里：每一站先讲这里在发生什么，末尾用一行小字点一句"由此 · 红心"。看的人先看到事实，再看到主题。

五心落在哪一站具体讲什么
红心 · 家国与地方 02 实训区 二十八个中高职专业长在港城的产业链上：化工、机电、纺织、商贸。学校牵头江苏扬子江职业教育集团（42 所职校、45 家骨干企业），现代学徒制试点 7 项，学生毕业进的是隔壁的厂；国家级实训基地同时给企业做职工培训和技能鉴定。
仁心 · 服务与照顾 06 食堂与宿舍 食堂、宿舍、洗衣、医务、快递一条线写清楚。家长最想知道的不是"条件好"，而是"我孩子的一天怎么被照顾顺"。
恒心 · 坚持与成长 01 图文中心、05 运动场 晚自习的灯；连续二十三届张家港市技能竞赛金杯、连续十年省技能大赛先进学校。金杯背后是傍晚的跑道和每天多练的那一小时。
匠心 · 精品与手艺 03 智造车间、07 展厅 一人一机、件件过检验；10 个校内实践基地，数控技术应用为国家级；全国技能大赛 78 金 26 银 5 铜，展厅里摆的是学生自己做的服装、模型、界面。
创心 · 数字与体验 04 云端机房、整页交互 信息工程系的机房；而这个页面本身就出自这排机器——卷轴拉开换景、七站点开、示意图联动，数字技术在这里既是内容也是展品。

03结构与交互

整页是一条向下的路线，七段各自解决一个问题，不做并列的卡片堆。这七段的顺序在后台可以调，也可以整段关掉。

段落解决什么关键交互
首屏三秒说清这是什么竖排印章、细红压线、向下提示
01 校园长卷先把场域铺开两根红漆轴头，滚到这一段自动缓慢向两侧拉开：先逐张翻过 1984—2024 的年份卡，拉到底最后是校门实景
02 数字用可核对的事实建立信任进入视口后数字从 0 补间到实际值
03 七站导览让人自己决定看哪一站点开一站展开一段，左侧目录式排布，右侧校园示意图高亮对应楼、定位点跟着走
04 系部专业看专业、看办学层次五个系部手风琴，一次只开一个
05 匠心与荣誉看四十年的来路时间线节点逐个亮起，右侧三张新闻图
06 招生信息把看的人变成来的人五步流程、两场开放日时段表、地址与二维码

导航只留五项，页脚补上设计说明与学校相关链接。手机上导航收进抽屉，七站仍是点击展开，示意图缩到列表上方，长卷照旧可以拉开。

另外，右下角常驻一个「问校园」按钮：点开是一层面板，22 组固定问答按关键词命中，答不上来就直说不知道，并建议换个问法或去官网、问招生办。

04技术实现

前台是纯静态的：一份 HTML、一份 CSS、两份 JS，没有框架、没有外链字体和图标库。把文件夹拷到任何地方双击就能打开，也可以直接放到 GitHub Pages 上。内容单独存在 content.json，由后台改、由前台读，改文案不用碰代码。

  • 内容与页面分离：content.json 是唯一数据源，node tools/build.mjs 把它编译成 assets/js/site-data.js（挂在 window.__CONTENT__ 上）。之所以不直接 fetch 那个 json，是因为 file:// 协议下读本地 json 会被浏览器的同源策略拦掉，双击就白屏；编译成 js 之后双击照样能看
  • 运行时渲染：index.html 是个空壳，assets/js/site.js 按 sections 里的顺序把七段拼出来。后台调顺序、关板块，前台立刻跟着变
  • 卷轴拉开：父级 sticky 占住视口，进入视口 35% 时触发一次，卷面宽度用 6 秒过渡从 5% 走到 100%，边拉开边翻帧，翻到最后停在门面图
  • 七站展开：点标题给该条加 .is-open，用 grid-template-rows: 0fr → 1fr 做高度过渡，同时把示意图对应楼高亮、定位点移过去
  • 示意图联动：SVG 每块写 data-block，JS 按名字找块，把定位点移到块的右上角，标签同时转白
  • 数字补间：IntersectionObserver 只触发一次，rAF 里按 easeOutCubic 跑 1300ms
  • 问校园：每条问答有关键词表，访客的话去和关键词比对，命中词越长、命中个数越多得分越高，再叠一个后台可调的权重；最高分低于阈值就当答不上来，如实说不知道，并建议换个问法或去学校官网、问招生办
  • 版式层次：全站分三级——标题深黑、正文中灰（对墨色 74%）、辅助更淡（48%），透明度和字距同步拉开，灰阶全部由主色 mix 出来，换了主色层次不会散
  • 优雅降级：系统开启"减少动态效果"时，所有过渡与视差关闭，内容直接呈现
  • 可访问性：语义化标签、aria-expanded、键盘可聚焦、正文对比度按 AA 校对

07内容后台

老师提了一个很实际的问题：这个页面是死的，招生办想换句话、换张图、加一条问答，都得找人改代码。所以补了一套后台——前台照旧是纯静态页面，后台是本地跑的一个小服务，改完点保存，前台刷新就变。

怎么开

双击 源码\启动后台.bat ← 最省事，浏览器会自动跳转 等价的手动做法： cd 源码 node server.mjs 前台 http://127.0.0.1:7717/ 后台 http://127.0.0.1:7717/admin/ 口令 首次启动是 admin123，进后台后右上角「改口令」

后台页面必须从 http://127.0.0.1:7717/admin/ 进。直接双击 admin/index.html 是从文件系统打开的，连不上服务，页面会直接提示这一点——这个坑我自己踩过，所以专门做了拦截提示。

后台只用 Node 自带的 http / fs / crypto 三个模块，不装任何依赖，不用数据库——内容就是 content.json 这个文件本身。所以换台电脑把文件夹拷过去，node server.mjs 一样能跑。

三个页面各管什么

页面能改什么对应老师说的哪一条
板块排版七段的上下顺序、显示或隐藏；纸色（整页底色）、次纸色（分段与页脚）、墨色（标题正文）、主红（强调按钮）、金（线）、天空（首屏背景）六个颜色，各带预设与取色器，可一键恢复默认；对比度、疏密、图片灰度"再加其实已经乱了"——顺序和显隐收在一处管；"颜色、字体、灰度分度"——颜色和三个滑竿直接调层次
内容编辑页头、首屏、长卷八帧、八个数字、七站、五个系部、时间线与新闻、招生流程与时段表、页脚，每一句文字和每一张配图"不如把原有的东西层次做丰富"——层次先用样式做好，内容再按段填
问答库增、删、改、排序、启停；每条有分类、权重、关键词表、答案"可以给 ai 加入新的问答回答"

为什么这么设计

  • 后台不接管前台：后台只写 content.json，前台只读编译好的 site-data.js。关掉服务，前台照样双击能看，也能扔到 GitHub Pages 上
  • 问答是可编辑的数据，不是模型：没有调用任何在线大模型，判断靠关键词匹配加权重。好处是断网能用、答什么完全可控、不会瞎编；代价是问法太偏就答不上来——所以新增问答时关键词要写全，把家长可能的问法都列进去
  • 登录够用就行：口令用 scrypt 加盐存哈希，会话放在内存里，服务只听 127.0.0.1——它本来就是给招生办在自己电脑上用的，不对外开
  • 顺手补的两处安全：静态文件走白名单，server.mjs、口令文件、版本快照不会被当网页发出去；上传只收图片并限制大小

答辩时怎么演示

开两个窗口：左边后台改一句文案、点保存；右边前台刷新，字变了。再到「板块排版」把纸色从宣纸换成米白、主红换成胭脂，保存后前台马上换色；最后打开「问答库」加一条新问答，回前台问一句，答案就出来了。

改完怎么上线

线上挂在 GitHub Pages：展厅 https://gxglad.github.io/yyt/，仓库 github.com/gxglad/yyt，主分支 main，Pages 直接读仓库根目录——而仓库根目录就是这个「源码」文件夹。所以不用再往别处拷文件，在 源码 里提交推送就等于发布：

node tools\build.mjs ← 改过 content.json 才需要（后台保存会自动做） git add -A git commit -m "改了什么" git push origin main ← 本机要走代理，见说明.txt 第五节的完整命令

等一两分钟线上就是新的。后台的 server.mjs 和 admin/ 会一起被传上去，但 Pages 只当静态文件存着，不会被当接口调用——它始终是本地工具。

08可拓展

  • 开放日预约接真实表单（问卷或后端），提交后回执进入招生老师的表格
  • 问答库接一个在线模型做兜底：关键词没命中时让模型按已有答案的范围改写，仍然答不上来才说不知道
  • 后台加多账号与操作日志，招生办几个人一起用
  • 加一段 30 秒无声循环视频替换长卷，弱网下退回图片
  • 英文版与繁体版，服务外籍家长与港澳台招生
  • 接入校园实景全景图（全景相机拍摄的 8K 等距柱状图），做成可拖拽的 360° 站点
