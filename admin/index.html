怎么弄这个 Token
  1. 打开 github.com/settings/personal-access-tokens/new（要先登录 gxglad）
  2. Token name 随便填；Expiration 给个够用的时间
  3. Repository access 选 Only select repositories，只勾 gxglad/yyt
  4. Permissions → Repository permissions → 把 Contents 改成 Read and write
  5. 点最下面 Generate token，复制 ghp_ 开头那串，粘到上面

Token 只存在这台电脑的浏览器里，不会写进仓库。漏了就回那个页面 Revoke 作废再生成一个。
